# Does an instance member that accepts the concept's witness accept every
# reasonable callable? `any` accepts soft or valid: the callable is one an
# instance may refuse, but checking it must not be a hard error. A void
# result is `soft` where the context cannot hold void and `any` for
# std::expected, which can.

# recorded outcomes are in docs/probes.md.

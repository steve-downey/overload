Detailed Description

template<class Impl>
struct overload::derive_functor< Impl >

Derivation base for Functor instances. Impl supplies fmap(f, v); replace is derived from it unless Impl supplies its own. Impl is a protected base, as in beman.transpose, so the instance exposes only the operations this base declares.
